# OmniGuard AML — V1 (as built, 2026-10-16)

Dual-pipeline financial-crime compliance platform. One stack, one deployment,
two jobs: investigate live alerts, and stress-test the controls that raise them.

## 1. What it does

**Pipeline A — Investigation (downstream).** Takes a flagged alert and returns
a disposition, never an action: `RECOMMEND_ESCALATE`, `RECOMMEND_CLOSE`, or
`CONFLICT_HUMAN_REVIEW`. Path: fetch + sanitize → deterministic features →
ML composite score → versioned policy retrieval → parallel Investigator and
Evidence-Gated Challenger LLMs → deterministic citation/numeric verification →
boolean adjudication → append-only audit row → hard human gate (analyst
decides; staleness check triggers rerun if new transactions arrived).

**Pipeline B — ScenarioLab (upstream).** Takes a plain-text risk concern and
returns a control weakness report. Path: ingest concern → LLM authors scenario
*specs* (suspicious variations + benign lookalikes) → deterministic generator
builds exact transactions → SHA-256 locks expected outcomes *before* the
control runs → adversarial challenger review → human signoff → control
executes in pure code → MATCH/MISS/OVER-ALERT report with a mandatory
"what was NOT tested" section and evidence-pack hash.

## 2. What it uses, and why

| Layer | Choice | Why (decision ref) |
|---|---|---|
| API | FastAPI, key-auth, CORS for dev UI | async, OpenAPI free, thin enqueue-only routes |
| Orchestration | LangGraph StateGraph (Graph 1, `interrupt_before` gate); staged functions + gates (Graph 2) | crash-safe state + real human gates, no LLM judge |
| LLM | NVIDIA NIM: Super-120B (Investigator/Author), Lightning-30B (Challengers + fallback) | NIM serves the Nemotron chain; Bedrock kept as an untested alternate; 552B unservable on free tier (D16/D18) |
| LLM safety | temp 0, strict JSON + validation + repair, 30s idle kill, 300s deadline, smart retries, fallback chain | free-tier stalls bounded and logged, never silent (D15/D16) |
| DB | PostgreSQL 16 + pgvector HNSW, 5 schemas | canonical store; vectors only for policies/scenarios, never transactions |
| Local fallback | SQLite + in-process queue + mock LLM | zero-infra runs; mock schemas identical to live |
| ML | LightGBM/HistGB (held-out argmax shipped) + IsolationForest, NetworkX graph features, SHAP | interpretable, in-process, no serving infra |
| Tracking | MLflow (params, held-out metrics, eval comparisons) | honest numbers, no serving infra |
| Deploy | Docker lean profile (postgres+redis, host :5433 — local PG18 owns :5432) | fits 8 GB box with 3 GB WSL cap |
| UI | Vite + React, AlphaCapMatch layout in black, key in memory only | readable cards/tables, raw evidence collapsible |
| Tests | 37 pytest (SQLite + Postgres both green) | gates per phase, including secret-grep and dialect parity |

## 3. Design principles (refusals)

No auto-close (human gate always fires) · no Text-to-SQL (parameterized
helpers only) · no multi-round LLM debate (single parallel pass) · no LLM as
judge or calculator (boolean adjudicator, precomputed features) · no vector
search on transactions (exact SQL) · no silent mock (STRICT mode fails loud) ·
audit is append-only (triggers + role separation).

## 4. Flowcharts

### Investigation
```
POST /investigate/{id} → ARQ/fallback queue
  → fetch_and_sanitize (SQL + NetworkX + injection regex + XML sandbox)
  → ml_risk_scoring (0.7·supervised + 0.3·anomaly + SHAP)
  → retrieve_policies (pgvector HNSW + typology_tag filter, top 3–5)
  → investigator ‖ challenger (parallel LLM, strict JSON)
  → verify_and_adjudicate (tx/policy/numeric checks + boolean logic)
  → write_audit_record → human_gate (pause) → review (staleness check → finalize/rerun)
```

### ScenarioLab
```
POST /scenario/ → ingest_concern
  → author_scenarios (LLM specs only, never raw rows)
  → generate_transactions (deterministic code)
  → lock_expectations (SHA-256 sealed)
  → challenge_scenarios (label-flip/leakage/consistency rubric)
  → human_signoff → execute_control (48h pass-through rule, code)
  → compare_and_report (MATCH/MISS/OVER-ALERT + NOT-tested + evidence hash)
```

## 6. Measured results (v1 close)

- **ML held-out** (n=338 account windows, group split): LightGBM F1 **0.545**
  (shipped, argmax); graph lift +0.016 (negligible, reported).
- **50 distinct cases** (PaySim + synth, mock): fraud never closed (4 esc / 11
  human), clean mostly closes, injection 5/5 quarantined, citation **1.000**.
- **Live NIM smoke** (n=6): citation 0.667 (title-cites → human review, working
  as designed), tokens 12.7k dual vs 9.9k single, 1 mock-degrade logged.
- **Limits:** small data, modest scorer, congested free tier — pipeline logic
  verified, scorer and inference are the stated limits.
